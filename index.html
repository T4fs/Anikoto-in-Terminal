An!KOTO

watch anime in your terminal

Anikoto is a fast terminal user interface for browsing and streaming anime — search anidb.app right from your terminal, pick sub or dub, and play in mpv or vlc. No browser needed.

View the source on GitHub

features

  • search anidb.app and browse results from your terminal
  • sub / dub toggle per episode
  • multiple quality sources (1080p / 720p / 360p) with automatic selection
  • mouse support — click the made by t4fs button to open the author's GitHub
  • plays in mpv, vlc, iina, or haruna
  • cross-platform: linux, macos, windows — written in Go with bubbletea

quick start

git clone https://github.com/T4fs/Anikoto-in-Terminal
cd Anikoto-in-Terminal/anikoto
make build
./build/anitui

windows

cd Anikoto-in-Terminal/anikoto
go build -trimpath -o "$HOME\.anitui\anitui.exe" ./cmd/anitui
"%USERPROFILE%\.anitui\anitui.exe"
